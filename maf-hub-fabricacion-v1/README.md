# MAF HUB · Fabricación V1

Base funcional para integrar el control de fabricación al programa general de MAF Automation.

## Incluye

- Navegación tipo plataforma general.
- Dashboard inicial del módulo.
- Árbol proyecto → subensamble → pieza.
- Ficha de pieza.
- Plano vigente y revisión.
- Ruta de fabricación.
- Asignación de responsables.
- Actualización de estado.
- Bitácora de anotaciones.
- Personal del taller precargado.
- Esquema SQL con usuarios, roles y RLS.
- Diseño adaptable a computadora y celular.

Abre `index.html` para ver la demostración local. Consulta `docs/INTEGRACION.md` antes de conectar Supabase.
